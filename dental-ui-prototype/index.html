2 · 设计 Token —— 字体层级
Segoe UI / 微软雅黑（系统字体，零加载）；数字、金额、时间一律等宽对齐（tabular-nums）。

3 · 设计 Token —— 圆角 / 阴影 / 动效
圆角：卡片 10px · 按钮 8px · 徽章 5px；阴影单层克制；动效全部 ≤250ms 且支持系统减弱动态效果。

4 · 组件 —— 按钮（四档 · 高 32px）
约定：删除 / 退费等危险操作一律用文字按钮 + 确认弹窗，不用大色块。
5 · 组件 —— 表格 + 状态徽章
表头 12px muted、行高 40px、hover 浅底；状态只用徽章表达。
