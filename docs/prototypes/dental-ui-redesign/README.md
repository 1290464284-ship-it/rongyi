# Dental Clinic V2 · UI 改版原型

静态可交互原型，保留原版配色，重点展示布局、动效、阴影和组件体系。

## 页面

- 登录页
- 工作台（统计卡片、趋势图、今日预约、待办、快捷操作）
- 患者管理（搜索筛选、列表、新建患者弹窗）
- 预约排班（时间轴、医生 Tab）
- 临床工作台（候诊 / 就诊中 / 已完成队列）
- 收费管理（收费统计、账单列表）
- 组件库（核心、通用、领域三层组件）

## 组件库

- 核心：Toast、确认弹窗、抽屉、日期、骨架屏、空/错误状态、Switch、Radio、分段控制、焦点态
- 通用：下拉菜单、可搜索多选、Tooltip、批量操作条、折叠面板、时间线
- 领域：收费项目树、步骤条、候诊看板拖拽、影像上传、牙位图、报告预览

设计约定：配色使用 `apps/v2/src/web/styles.css` 的原版 token；动效统一使用 120ms / 200ms / 250ms 三档时长和 `cubic-bezier(0.2, 0.6, 0.25, 1)` 缓动；系统开启“减弱动态效果”时动画自动降级。

## 运行

直接双击 `index.html`，或启动本地静态服务器：

```powershell
cd docs/prototypes/dental-ui-redesign
python -m http.server 8900
```

然后打开 `http://localhost:8900`。演示账号：`admin`（任意密码即可进入演示）。

## 文件

- `index.html` 页面骨架
- `styles.css` 布局、配色、动效、组件样式
- `app.js` 页面渲染与组件交互
- `data.js` 模拟数据
- `screenshots/` 页面与组件效果截图
