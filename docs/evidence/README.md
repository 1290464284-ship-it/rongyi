# Evidence Archive

Historical verification evidence for the V2 desktop app. These files are
archival and are not part of the application build.

- `t2r22-evidence/` - T2R-22 test run screenshots and result JSON. The
  one-off probe scripts were removed in Round 9; only archival records remain.
- `v2-walkthrough/` - Electron light/dark walkthrough screenshots and result
  JSON.

Do not rely on this directory from application code or CI.
