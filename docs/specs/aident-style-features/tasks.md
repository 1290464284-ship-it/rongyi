### [ ] Task 10: 库存补货建议
- **Priority**: medium
- **Depends On**: Task 2
- **Description**:
  - DailyScheduler 注册子任务 `InventoryReplenishment`：
    - 每个 inventory 最近 90 天（可调）消耗 = sum(InventoryTransaction 中 OUT 类型数量)
