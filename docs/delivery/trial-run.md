# 受控试运行记录

## 目的

内部正式交付前，在隔离/受控诊所环境使用真实业务数据试运行 2-4 周，验证诊所人员不依赖开发者即可完成一周真实业务。

## 试运行范围

- 建档、预约、到诊、就诊、病历、收费、会员、库存、随访、备份。
- 员工登录、权限、密码修改、排班、考勤、请假。
- 微信未配置通道时的“未开通”提示。
- API 重启、备份恢复、升级安装、回滚准备。

## 记录字段

每条问题记录至少包含：

```text
日期：
操作人：
模块：
现象：
复现步骤：
期望结果：
实际结果：
影响级别：P0/P1/P2
处理状态：待修复/已修复/已关闭
版本：
```

## 冻结条件

- 连续 1 周无 P0 问题。
- 所有 P1 问题有修复计划或已登记。
- 备份、恢复、升级演练全部通过。
- 管理员完成初始化并修改默认密码。
- 最终版本冻结为 `2.2.0`。

## 冻结动作

1. 记录试运行结束日期。
2. 汇总问题清单和修复结果。
3. 在 `MATURITY.md` 中登记冻结版本。
4. 将试运行结论写入内部交付记录。

未达到冻结条件前，不得将内部版作为正式交付版本发布。
