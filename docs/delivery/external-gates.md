# 公开商用前的外部交付门禁

以下事项无法在当前本地自动化环境中完成，需要证书、真实诊所数据、运营人员和正式发布渠道参与。

## 签名与平台信任
- 购买并配置 Windows CA 代码签名证书。
- 使用签名证书重新构建安装包并验证签名。
- 消除 SmartScreen 警告并完成 Windows Defender 信任流程。

## 真实数据演练
- 使用真实诊所数据库执行一次迁移、备份、模拟损坏、恢复、升级和一致性核对。
- 在磁盘写满、备份文件损坏、加密密钥丢失场景下执行人工恢复步骤。
- 使用真实诊所数据做 2 至 4 周受控试运行，并记录业务阻断问题。

## 正式发布准备
- 配置公开更新渠道、发布前健康检查、回滚流程和版本说明。
- 发布隐私政策、数据采集声明、许可协议和客服/SLA。
- 完成供应链审计、第三方依赖许可复核和安全响应流程。

## 最终验收
- 由诊所人员在不依赖开发者的情况下完成至少一周真实业务。
- 以“备份可恢复、升级不丢数据、故障可定位”作为冻结 2.2.0 的验收条件。
