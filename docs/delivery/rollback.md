# 版本回滚

## 原则

回滚必须保留当前数据库，优先使用备份恢复，不直接覆盖用户数据目录。

## 回滚步骤

1. 在旧版本回滚前，先备份当前版本数据并验证。
2. 卸载当前版本，但不要删除 `%APPDATA%/Dental Clinic V2`。
3. 安装旧版本安装包。
4. 启动旧版本，确认数据目录中的 `v2.sqlite` 可被旧版本读取。
5. 如数据库结构不兼容，使用旧版本对应的备份恢复。
6. 核对患者、收费、库存、随访数据。

## 数据库升级兼容

升级使用版本化迁移记录 `schema_migrations`。降级时若新迁移已写入，旧版本可能无法读取；回滚前必须确认数据目录备份。

## 回滚验收

- 旧版本可启动并登录。
- 核心业务数据可查询。
- 备份、恢复、桌面端设置可用。
- 操作日志能定位本次回滚动作。
