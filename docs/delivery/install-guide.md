# 安装与首次启动

## 适用环境

- Windows 10/11 x64。
- 建议 4GB 以上内存，20GB 可用磁盘空间。
- 无需安装 Node.js、SQLite 或浏览器。

## 安装步骤

1. 双击 `Dental Clinic V2 Setup <版本>.exe`。
2. 安装程序默认安装到当前用户目录，可修改安装路径。
3. 等待安装完成，勾选“立即运行”或从开始菜单启动。
4. 首次启动会初始化本地数据库并导入内置演示兼容库。

## 首次登录

默认管理员：

```text
用户名：admin
密码：admin123
```

首次登录后立即修改密码，并按 `admin-init.md` 完成员工、角色和业务字典核对。

## 首次启动验证

1. 登录后确认工作台可显示患者、预约、收费、库存、随访、备份等入口。
2. 打开“系统管理 -> 桌面端”，确认 API 端口显示为本地随机端口，本地服务状态为正常。
3. 创建一个测试患者并创建一个预约，确认可正常保存。
4. 执行一次手动备份并验证，确认备份文件生成在用户数据目录。

## 数据位置

运行时数据保存在 Windows 用户目录下的应用 `userData` 中：

```text
%APPDATA%/Dental Clinic V2/data/v2.sqlite
%APPDATA%/Dental Clinic V2/backups
%APPDATA%/Dental Clinic V2/logs
```

不要在程序运行期间手工替换或删除这些文件。
