# 管理员初始化指南

## 1. 修改默认密码

登录后进入“员工”页或通过“系统管理”中的员工管理修改 `admin` 密码。默认密码不得长期保留。

## 2. 建立员工与角色

按诊所实际岗位创建员工账号，至少覆盖：

- 管理员：负责系统、备份、恢复和权限。
- 医生：负责就诊、病历、治疗、处方和影像。
- 前台/护士：负责建档、预约、收费、会员和随访。

确认每位员工只获得完成本职所需的权限。越权访问场景必须被导航隐藏且 API 拒绝。

## 3. 核对业务字典

在正式录入前核对以下内容：

- 患者字段、性别、来源和标签枚举。
- 预约类型、状态和冲突规则。
- 收费项目、支付方式、退款原因。
- 库存分类、单位、供应商和最低库存。
- 随访模板、间隔天数和负责人。
- 排班、考勤、请假类型。

核对结果应写入诊所内部交接记录。

## 4. 配置微信通道

微信发送默认显示“未开通”，发送按钮禁用，不会伪成功。

如需启用，请由实施人员配置：

```text
V2_WECHAT_API_URL
V2_WECHAT_APP_ID
V2_WECHAT_APP_SECRET
```

未配置真实通道时，系统仍可正常完成随访，但微信消息不得标记为已发送。

## 5. 设置备份习惯

建议每天至少一次自动备份，并在每周手动验证一次备份。可恢复性是内部交付的硬性验收项。
