# 运维交接手册

## 日常操作

1. 前台员工使用 `DOCTOR` 账号登录，老板使用 `BOSS` 账号登录。
2. 每天下班前确认当日收费、预约、随访数据可查询。
3. 每周执行一次手动备份并点击“验证”，确认备份文件可恢复。
4. 系统自动备份默认启用；自动备份失败时系统会写入业务告警。
5. 升级前先手动备份并验证，再安装新版安装包；安装后确认登录和核心页面正常。

## 日志与崩溃上报

- 桌面端日志：`%APPDATA%/Dental Clinic V2/logs/desktop.log`
- API 日志：`%APPDATA%/Dental Clinic V2/logs/v2.log`
- 指标：`%APPDATA%/Dental Clinic V2/logs/metrics.json`
- 崩溃上报：设置 `V2_CRASH_REPORT_URL` 为 HTTPS 端点后启用；未设置时只落本地日志。

## 备份制度

- 自动备份周期默认按 `V2_AUTO_BACKUP_INTERVAL_MS`，保留数量按 `V2_AUTO_BACKUP_KEEP`。
- 每周至少人工验证一次最新备份。
- 恢复前先复制当前 `v2.sqlite` 作为安全副本，恢复后核对患者、收费、库存、随访数量。

## 支持交接信息

上报问题时至少提供：

- 版本号（桌面端设置页可查看）。
- 操作步骤与截图。
- `desktop.log` 与 API 日志。
- 最近一次成功备份的文件名。
- 影响范围：登录、数据写入、备份恢复、升级。

## 权限说明

当前版本只有两个角色：

- `BOSS`：全部菜单，负责系统、备份、恢复和权限。
- `DOCTOR`：临床与日常业务，财务、库存、人事、系统菜单由权限配置控制。

前台、护士、收银等岗位使用 `DOCTOR` 账号，并在“权限”页按资源收窄权限。
