# 交付验收检查清单

## P0：必须全部通过

- [ ] 安装包可在全新 Windows x64 机器安装并启动。
- [ ] 默认管理员可登录，修改密码后旧密码失效。
- [ ] 建档 -> 预约 -> 到诊 -> 就诊/病历 -> 收费/支付闭环可完成。
- [ ] 会员、库存、采购、加工、随访页面可完成各自主流程。
- [ ] 备份创建、验证、恢复、重启后数据一致。
- [ ] 微信未配置时明确“未开通”，不伪成功。
- [ ] 重复提交、非法金额、预约冲突、库存不足、越权访问均有明确错误提示。
- [ ] API 重启后前端可自动恢复。
- [ ] API 本地只监听 `127.0.0.1`，深健康/指标接口需要管理员权限。
- [ ] Electron 导航白名单、CSP、窗口安全策略已生效。
- [ ] 崩溃日志、更新状态、托盘图标、窗口状态记忆可用。
- [ ] 交付演练脚本 `delivery:drill` 通过。
