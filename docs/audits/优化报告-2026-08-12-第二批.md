# 优化报告-2026-08-12-第二批
日期：2026-08-12

范围：keyset 分页落地前端、索引基准、日志采样配置化、前端小项、ADR、跨模块搜索推广、超十万行聚合快照。

## 1. keyset 分页落地前端

- `useCrudResource` 新增 `cursorPagination` 选项：查询键与列表路径使用 `cursor`，支持 `nextCursor` / 前进后退栈 / 删除末页回退。
- `CrudPage` 在启用游标分页时渲染上一页/下一页按钮。
- `PatientsPage` 启用游标分页（大表列表）；`fetchAllPages` 上一批已支持游标。
- 新增游标分页回归测试。

## 2. 时间列索引与基准

- `createPerformanceIndexes` 补充 Visit(startTime)、FollowUp(clinic+status+planDate)、FirstExam(createdAt)、InventoryTransaction(clinic+createdAt+type)、WechatReminder(clinic+scheduledDate+status) 索引。
- `benchmark-load.ts` 现按生产顺序创建性能索引后跑基准；10 万级全部阈值通过（insert patients 765ms / charges 1366ms / dashboard 106ms / sync page 77ms）。

## 3. 日志采样配置化

- 新增 `V2_REQUEST_LOG_SAMPLE_RATE` 环境变量（默认 0.01），写请求/错误/慢请求仍全量记录。

## 4. 前端小项

- `WechatReminderSettings` 提交前校验天数 0-365。
- `SchedulesPage` 模板/员工查询失败时展示错误态并可重试。

## 5. ADR 归档

- 新增 `docs/architecture/optimization-decisions-2026-08-12.md`，记录区间查询、keyset、smoke 公共库、日志采样、聚合快照、全局搜索六项决策。

## 6. 跨模块搜索推广

- `GlobalSearchPage` 增加资源筛选（患者/库存/收费/预约/随访等）与快捷跳转。
- 帮助面板标注“Ctrl+K 全局搜索”支持跨模块。

## 7. 超十万行聚合快照

- 新增迁移 v157 与 `stats-aggregate.ts`：
  - `StatSnapshot`：dashboard 六项指标，写路径 `trackResourceWrite` 失效。
  - `ReplenishmentSnapshot`：90 天消耗聚合，写路径失效 + `MAX(createdAt)` 二次校验。
- `StatsService.dashboard` / `ReplenishmentService.generate` 在超过 10 万行阈值后走惰性物化快照，未达阈值保持实时查询。
- 新增快照读写/失效回归测试。

## 验证

- 全量单测 224 文件 / 2265 用例全绿；typecheck / lint / knip 全绿。
- `benchmark:load` 全阈值通过。
- `smoke:delivery` 全链路通过（含迁移与写失效路径），`security:scan` 通过（691 文件）。
