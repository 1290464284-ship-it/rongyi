# 深度审计报告-第四十三轮-主报告
日期：2026-08-12
基线：`059e32c`。本轮启用 3 个只读交叉复核代理（HTTP/权限/文件、前端组件与剩余页面、脚本/CI/遗留导入），并修复 24 处问题。
## 1. 权限与安全（HTTP 代理）
- 跨诊所建号：BOSS/ADMIN 创建账号时 `clinicIds` 必须落在自身实际所属诊所内，禁止 A 诊所管理员给 B 诊所建号提权。
- 同步模块权限：`sync/full`、`sync/pull`、`sync/push`、冲突解决按表映射 `RESOURCE_PERMISSION_MAP`，只授予 `system` 的账号不再能拉取/写入业务表。
- 病历修改审核：仅 BOSS/ADMIN 可审核，且禁止自审自批；新增回归测试。
- 批量导入模块权限：与通用资源路由一致，在角色之上校验模块权限。
- 布尔权限严格解析：`"false"`/`"0"` 不再被当成 true 变成授权，非法值抛 400。
- 微信提醒配置 PATCH 限定 BOSS/ADMIN。
- 搜索限流改用 DB 后端，多实例共享同一 300/min 窗口。
## 2. 前端（组件代理）
- MultiSelect 键盘流：菜单打开后 ArrowDown 聚焦搜索框，不再误关菜单。
- UsersPage：角色数据加载失败时禁止编辑/保存并显示错误，避免 `roles: []` 静默清空附加角色。
- 系统操作页审计清理补 in-flight 守卫；文件选择竞态按代际丢弃过期读取。
- Tooltip 焦点态补 `visible` CSS，键盘用户可看到提示。
- DesktopSettings：`available -> none` 时清空下载按钮状态。
- DataTable：`keyField` 为 null/缺失时回退行索引，消除 React key 冲突。
- 经营分析打印补防重与按钮禁用；医生行 key 回退索引。
- ResourceHub：导航权限加载失败时显示错误与重试，不再静默隐藏 boss-only Tab。
## 3. 脚本/CI/遗留导入（脚本代理）
- `ensure:legacy` 与 `verify:package` 强制 legacy 库敏感表为空，真实数据不再可能随安装包流出。
- legacy 导入改为临时文件复制 + 完整校验 + 原子替换，失败不破坏旧库。
- environment-drill 在 finally 中回收全部子进程，readiness 超时不再泄漏进程。
- repair-database 备份前 TRUNCATE checkpoint，修复备份不再丢失 WAL 数据。
- verify-foreign-keys 从 19 项扩到 37 项（Appointment/Visit/Charge/MedicalRecord/PaymentLedger/Dispense/InventoryBatch/PurchaseOrder 等）。
- run-smokes 未显式指定端口时动态挑选空闲端口，避免 Windows 保留端口段。
- v2-release：DB 校验移到 smoke 之后并对同一份 smoke 数据执行；升级冒烟补版本递增断言与升级后数据库完整性校验。
- license-scan 改为遍历真实 node_modules 依赖树（含传递依赖），618 个包全部通过；子路径 stub 与无版本测试夹具不再误报。
