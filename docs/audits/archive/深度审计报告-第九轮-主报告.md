## 本轮修复

1. 权限旁路：`/search`、`/workbench`、`/files`、`/stats/dashboard` 增加模块权限；用户收回 `patients/clinical/dashboard` 后直接调用这些接口返回 403。
2. 文件签名 CORP：`Cross-Origin-Resource-Policy: cross-origin` 中间件移到公共文件路由之前，打包版 `<img>` 可正常加载签名文件。
3. 崩溃上报：`https://` 上报改用 `node:https`，不再被 `ERR_INVALID_PROTOCOL` 静默吞掉。
4. 模板替换：`replaceAll` 改为回调替换，患者姓名中的 `$&`、`$'`、`` $` `` 不再被特殊替换符改写。
5. 清理脚本：`clean-artifacts.mjs` 补齐 `coverage-web` 和 `release-v2-internal`。
6. 空 clinic token fail-closed：`isClinicAccessible` 对空 clinicId 返回 false，避免旧 token 绕过租户过滤。
7. 日期校验：datetime 先校验真实日历日期，`2026-02-30`、非闰年 `2026-02-29` 拒绝。
8. Electron 窗口：修复 `createWindow` 局部 `state` 遮蔽，托盘存在时关闭窗口改为隐藏。
9. 审计缓冲：重试在途时不再静默丢行，补 `audit-drop` 告警。
10. 跨诊所权限模型：新增迁移 153，`UserRole` / `UserPermission` 改为 `clinicId` 复合主键；用户查找优先走 `UserClinic` 成员关系。
11. 文件物理清理：新增 `DELETE /api/v2/files/:name`，仅上传者或 BOSS 可删除，先物理删除再软删记录。
12. 发布流程：`v2-release.yml` 的 Verify 阶段内置 lint、knip、全量测试、覆盖率和安全扫描，不再只依赖并发 CI。
13. 路由覆盖回归：新增 `route-coverage.spec.ts`，自动断言所有已注册受保护路由都命中 `routeRoleRules`。
14. UI 测试补充：新增 `CustomFieldsPage`、`BarcodeView`、Layout 交互与静态可访问性回归测试。
15. 重复组件重命名：`FollowUpDialog`、`FormFields` 改为语义化文件名并更新全部引用。
16. Layout 拆分：抽出 `GlobalSearchForm`、`BackupStatusCard`、`HelpDialogs`，Layout 只保留组合逻辑。
17. 文档同步：README 与本报告测试数统一为 170 个文件 / 1436 个用例。

- 真实诊所数据迁移与对账、干净 Windows 物理机验收、2-4 周试运行尚未执行。
- 正式代码签名证书和 GitHub production environment reviewers 仍需外部配置。
- 日志与文档中仍存在少量过期数字，README 测试数已同步为 1512。
