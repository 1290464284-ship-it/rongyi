## 2. 后端
- 通用资源 CRUD 状态机保护：appointments/visits/treatments/firstExams 的 status、prescriptions 的 status/processedAt/chargeId/dispenseId 不再允许经 `/resources/*` 直写；通用创建强制初始状态（BOOKED/IN_PROGRESS/PLANNED/DRAFT/DRAFT），sync/bulk-import 路径不受影响。
- sync push：SyncChange 落库失败会回滚整个批次并逐条返回失败，不再出现“业务已写、变更未记”的半提交。
- doctorAnomalies：医生成员关系同时认 UserClinic 与 User.clinicId，并补 `deletedAt IS NULL`，仅 UserClinic 关联的医生不再漏报，且不跨诊所泄漏。
- 日期校验：抽出 `isValidCalendarDate/assertValidDateValue/assertValidDateTimeValue`，班次 weekStart、预约改期、随访执行时间统一拒绝 `2026-02-30` 这类不可达日历日期。
- 布尔解析：`parseBooleanStrict` 让佣金规则、班次模板、高值耗材路由不再把字符串 `"false"/"0"` 当 true。
- 微信发送：网关已投递但本地 markSent 竞争返回 0 时补偿为 SENT，避免消息留在可重试状态重复发送。
