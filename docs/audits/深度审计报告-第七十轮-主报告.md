# 第七十轮质量评分指标修复主报告

## 结论

本轮修复自动质量评分脚本的两个真实缺陷：mutation score 恒为 0，以及 OpenAPI 指标遗漏第 68 轮生成的 197 个 path。

## 完成内容

- `quality-score.mjs` 的 mutation 统计原来读取不存在的 `file.killed` 顶层字段，实际 Stryker 报告按 `file.mutants[].status` 组织；改为按 Killed/Timeout/Survived/NoCoverage 统计。
- OpenAPI 指标原来只统计核心 `openapi.json` 的 8 个 path；改为合并 core + `openapi.generated.json`，并输出 route entries、unique routes、unique route paths 与覆盖率。
- 新增 `scripts/lib/quality-metrics.mjs` 纯函数与 `quality-metrics.spec.mjs`，覆盖 mutation 统计与 OpenAPI 指标边界。
- 顺带确认 `openapi-routes.json` 的 224 条记录中 `GET /api/v2/files/:name` 是公开签名路由与受保护 JWT 路由两条真实注册，唯一路由为 223，唯一路径为 197。

## 验证

- typecheck、lint、knip、unit tests 通过：239 files / 2409 tests。
- 完整 `--sequence.shuffle` 通过：239 files / 2409 tests。
- `test:quality-score` 输出 mutation score 0.5959、routePathCoverage 1。
