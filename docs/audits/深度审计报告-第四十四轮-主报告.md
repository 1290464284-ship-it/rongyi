# 深度审计报告-第四十四轮-主报告
日期：2026-08-12
基线：`199a7b9`。本轮启用 2 个只读交叉复核代理（迁移/数据库引导/领域注册表、内部服务/校验/掩码/队列），并修复 20 处问题。
## 1. 迁移与数据库
- 新增迁移 158：无条件重建旧 legacy 表（MemberCard、ProcessingOrder、TreatmentPlanItem、PrescriptionItem、ProcessingOrderItem、InventoryReplenishmentSuggestion），修正旧 CHECK 拒绝 `INACTIVE`/`DRAFT`、子表缺 FK/NOT NULL 的问题；force 路径保留旧库扩展列，不中断升级。
- ChargeCombo/ChargeComboItem 语义回填：`isPublic -> type/active`、`creatorId -> ownerId`、`treatmentCatalogId -> catalogId`、`itemName -> name`。
- Clinic 唯一索引改为单列 `code`，新库重复诊所编码会被唯一约束拒绝。
- 迁移 146 回填改为 `INSERT OR IGNORE`，重放安全。
- 性能索引补 `BusinessAlert(clinicId,status,deletedAt,createdAt)` 与 `MemberCard(patientId,status,deletedAt)`。
## 2. 校验、掩码与 PII
- NPS 评分上限修正为 0-10，满意度汇总按 9/10、7/8、<=6 防御性分桶。
- 通用 CSV 导出对患者手机/身份证/微信/地址、供应商手机/银行账号、员工手机脱敏。
- 全局搜索不再返回完整手机号，统一走 `maskPhoneForExport`。
- 审计掩码集合补 `tempPatientPhone`。
- datetime 严格 ISO 格式校验，拒绝 `'1'`/`'2026'` 这类被 Date.parse 静默规范化的输入。
- 必填文本/枚举/关系字段拒绝空串与纯空白；布尔字段非法值显式拒绝。
- `maskPhoneForExport` 对 7 位及以下号码整体掩码，不再暴露全部数字。
- sync push 增加载荷形状校验（changes 必须是数组、上限 5000、逐条字段），畸形请求返回 400 而非 500。
- `parseStringArray` 直接接受已是数组的输入，不再把 `['a','b']` 静默变成 `[]`。
## 3. 脚本
- WeChat gateway smoke：证书与 openssl 都缺失时默认失败，只有显式 `V2_ALLOW_WECHAT_SKIP=1` 才跳过。
- `generate-legacy-resources` 在 legacy DB 缺失时失败并提示先运行 `ensure:legacy`，不再静默保留旧产物。
- upgrade-smoke 增加 trap：任何失败路径都回收子进程并清理临时目录。

- verify:database、verify:foreign-keys（37 项）、license:check（618 包）、ensure:legacy 全部通过。

- 审计缓冲断电丢最近 1 秒、打包实机升级、真实微信网关、CA 证书链路仍为约定范围外。
