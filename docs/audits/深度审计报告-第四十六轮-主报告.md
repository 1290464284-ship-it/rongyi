# 深度审计报告-第四十六轮-主报告
日期：2026-08-12
基线：`449bd83`。本轮启用 2 个只读交叉复核代理（Planck：前端横切面与上轮回归；Kierkegaard：基础设施/脚本/Electron/CI），并修复 15 处问题。
## 1. 前端
- CrudPage/useCrudResource：placeholder 旧数据期间禁用编辑/删除与行内写操作，`CrudRenderContext` 增加 `stale` 供业务行操作使用；避免翻页/搜索时对旧记录发 PATCH/DELETE。
- 全局搜索深链：库存深链改指向 `itemMaster` 资源 tab（支持 q 搜索）；AppointmentsPage/ChargesPage 增加 `initialSearch` 消费，列表查询带 `search` 并显示搜索框。
- Modal/Drawer 可访问性：`registerModalLayer` 增加根级分支 inert，弹窗打开时侧栏/顶栏等整页背景不再可 Tab 进入；Drawer 焦点逃逸随之被根级 inert 兜住。
- FormBuilder.RelationSelect：查询错误不再吞掉（显示错误文案），加载更多在请求中禁用，并加 10 页上限与“使用搜索筛选”提示。
- SearchableSelect：搜索输入改为 300ms 防抖；与 RelationSelect 一起把合并逻辑改为“同一查询键快照”模式，搜索/翻页/作用域重置后旧数据不会被合并回来，同时首次挂载数据正常合并。
- DataTable：超过 100 行改为窗口化渲染（滚动按 100 步进扩展），保留 500 行上限与提示，超大列表不再一次性同步渲染全部 `<tr>`。
## 2. 后端与基础设施
- secret-file：POSIX 上用 `O_NOFOLLOW` 打开并对 fd `fstat`，校验属主与 0600 权限后从 fd 读取，消除 stat/read 换文件与符号链接竞态；测试夹具显式写 0600，修复 Linux CI 会失败的问题。
- api-process 密钥清扫：POSIX 上仅清理当前用户属主的过期 `v2-secrets-*.json`，避免误删其他实例文件。
- 崩溃报告外发 fail-closed：`V2_ALLOWED_CRASH_REPORT_HOSTS` 未配置时不再默认放行任意 HTTPS 主机。
- 迁移并发：`duplicate column name` / `already exists` 也归入整轮重试分类，双进程并发 ALTER 不再直接启动失败。
- license-scan：scoped 依赖（`@scope/name`）不再被子路径 stub 过滤误跳过；抽出 `isSubpathStub` 纯函数并补单元测试，扫描包数从 618 增至 797。
- 大文件内存：`sha256File`、update-metadata、verify-update 改为 64KB 分块同步哈希；restore-backup 改为 1MB 分块流式解密并统一 try/finally 清理临时文件；verify-remote-release 安装包改为流式落盘 + 2GB 上限 + 下载大小校验。
- 内部发布版本校验：`latest.yml` 改为校验 `<base>-internal.*` 前缀，修复 internal release workflow 必然失败的问题。
