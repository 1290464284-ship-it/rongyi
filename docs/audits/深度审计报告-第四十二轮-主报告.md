# 深度审计报告-第四十二轮-主报告
日期：2026-08-12
基线：`acee03f`。本轮聚焦上一轮报告的残余 P3 与防御性收口：幂等无 key 原子性、批次创建锁守卫位置、资金路径租户过滤、docs 索引断链。
## 1. 修复内容
- 幂等无 `requestId` 时的原子性：`withIdempotency` 之前对无 key 调用直接 `return fn()`，`member-card` 等接口在未携带 `requestId` 时“改余额/积分 + 落流水”没有外层事务，中途失败会留下半套数据。现改为同步操作统一 `BEGIN IMMEDIATE` 包裹，成功 COMMIT、失败 ROLLBACK；异步回调保持原样。新增回滚/提交回归测试。
- `InventoryBatch.create` 的盘点锁守卫移入事务内，消除“守卫通过后、写入前被盘点锁定”的竞态。
- `ChargeService.cancel` 的软删除 UPDATE 补 `tenantAnd(clinicId)`，`ChargeItem` 级联软删同步补租户条件（防御性，前置查询已限定）。
- `RefundFlowService.reversal` 全部资金写路径补租户过滤：Charge 查询/更新、MemberCard 余额扣回、PaymentLedger 回退、Debt 查询/更新，避免未来调用方改动时引入跨诊所写入。
- `docs/audits/archive/README.md` 索引修复：第 6/7 轮链接改为 `../round-*`，补录第 40/41 轮，优化报告路径改为 `../`。
