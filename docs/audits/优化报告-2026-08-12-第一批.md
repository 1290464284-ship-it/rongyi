# 优化报告-2026-08-12-第一批
日期：2026-08-12

范围：审计后提出的六项优化全部落地。

## 1. 高频日期查询改区间条件

- `workbench.ts`：今日挂号/预约/进行中就诊由 `LIKE 'YYYY-MM-DD%'` 改为 `registeredAt/startTime >= dayStart AND <= dayEnd`，同时修正 UTC 前缀匹配导致的时区错位（+8 时区早间记录此前会被漏统计）。
- `wechat-reminder.ts`：预约提醒、治疗回访、首诊跟进三类候选由 `substr(datetime(...)) = date` 全表过滤改为 UTC 区间条件，可走时间索引。

## 2. 深分页 keyset 支持

- `Page` / `RepositoryQuery` 新增 `nextCursor` / `cursor`。
- `SqliteRepository.findMany` 在传入 cursor 时按 `id ASC` 游标分页，total 口径与第一页一致。
- 通用资源路由识别 `?cursor=` 并透传。
- `fetchAllPages` 优先使用游标逐页拉取，服务端不支持时回退原分页逻辑。
- 新增 repository keyset 回归测试。

## 3. smoke runner 公共库

- 新增 `scripts/lib/smoke-runtime.mjs`：`pnpmCommand`、`isPortFree`、`stopProcessTree`、参数注入防护。
- `run-smokes.mjs` 与 `delivery-smoke-runner.mjs` 改为复用公共实现，删除各自重复的端口探测与进程清理代码。

## 4. 前端旧数据反馈

- `InventoryReportPanel`：查询切换/刷新期间显示加载态，不再保留上一次报表误导用户。
- `RefundsPage`：新增 `GET /refunds/summary` 服务端全量状态汇总，替换“只统计前 200 条”的前端口径。
- `PlanBillingDialog`：未勾选明细时“划价”按钮禁用，避免无意义请求。

## 5. 日志与密码哈希

- HTTP 请求日志采样：仅记录慢请求（>200ms）、写请求、错误请求与 1% 普通 GET，健康检查默认不逐条记录。
- bcrypt 成本 10 → 12，并将 `DUMMY_HASH` 同步为成本 12，避免用户存在性时序侧信道。

## 6. 随访校验与全局搜索

- `FollowUpsPage`：提交前校验“已完成须填联系时间”与评分/疼痛度 0-10 整数范围。
- 顶栏全局搜索改为进入新的 `GlobalSearchPage`（`/search?q=`），展示跨资源搜索结果；`Layout` 放行该路由。
- 新增 `GlobalSearchPage.spec.tsx`。

## 验证

- 定向测试 170 用例通过；全量单测 223 文件 / 2262 用例全绿。
- `typecheck` / `lint` / `knip` 全绿。
