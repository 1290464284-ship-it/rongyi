# 深度审计报告-第四十一轮-主报告
日期：2026-08-12
基线：`755cba1`（上一轮 keyset 游标与快照修复）。本轮启用 4 个只读交叉复核代理（资金、库存、同步/状态机、前端），针对当前 HEAD 逐项核实历史风险，并继续深挖资金、库存、幂等、调度与前端数据正确性。
## 1. 结论
本轮确认历史报告中的多数 P1/P2 已在先前轮次修复（债务 PaymentLedger、积分/余额守卫、状态机条件更新、发药单 PENDING 事务内校验、目录价格 TOCTOU、前端明细加载失败放行、queryKey 冲突、fetchAllPages 参数覆盖、sync 事务内 await 等）。本轮新发现并修复 12 处真实问题：
### 库存/资金正确性
- 盘点批号管理商品会破坏库存一致性：`Stocktake.complete` 只改 `InventoryItem.stock`，不碰 `InventoryBatch.remainingQuantity`，两者永久背离。已改为批号管理商品禁止通过盘点直接调整库存（录入即拒绝），并在 `complete` 加防御性拦截。
- 盘点产生的 ADJUST 流水缺 `referenceType/referenceId`，盘点报表永远查不到真实盘点记录。已写入 `STOCKTAKE/<stocktakeId>`。
- `InventoryBatch.adjust` 在事务外读余量并算 delta，跨进程并发会丢失更新；锁守卫也在事务外。已改为 `BEGIN IMMEDIATE` 内重读 + `remainingQuantity = ?` CAS + 守卫内移。
- `InventoryBatch.remove` 删除前检查余量为 0 但 UPDATE 无余量条件，并发 adjust 后仍可删除。已加 `AND remainingQuantity = 0` 并抛冲突。
- 数量上界不一致：`returnItems`、批次 `create/adjust`、盘点 `recordCount` 均未限制 10 亿上限。已统一校验。
- `dispense()` 在事务外读明细/计划，并发 `updateDispense` 提交后仍按旧数量扣库存。已把计划读取与执行整体放进 `BEGIN IMMEDIATE`。
- 提成重算不清旧账：全额退款或医生移除后旧提成单残留。已在本期事务内删除不再出现的医生行、清空无计费期间。
- 提成明细独立四舍五入会超过实付基数（101 分两行各 50 得 102）。已从末行回退溢出。
- `quickCharge` 事务外读目录价格，存在与 charge-combo 同类的 TOCTOU。已改为事务内重读价格。
### 同步/幂等/调度
- `processing-flow.ensureSteps` check-then-insert 用 DEFERRED 事务且无唯一约束，双实例可 500 或重复步骤。已改 `BEGIN IMMEDIATE`。
- 批量导入在 `BEGIN IMMEDIATE` 内 `await repository.insert`。已改用同步 `insertSync`。
- `withIdempotency` 对“非 async 回调返回 Promise”会错误标记 COMPLETED。已在同步路径加失败保护。
- 幂等 PROCESSING 清理只按天执行，异常残留可锁 key 近 24 小时。已改为启动即清 + 每 10 分钟周期。
- 孤儿退出路径未冲刷审计缓冲。已补 `flushAuditNow`。
### 前端数据正确性
- 处方编辑明细回填失败仍可保存，会静默删除服务端既有明细。已加 `itemsLoadedRef` 门禁并在失败时显示错误、阻止保存。
- 病历表单就诊下拉在切换患者时仍显示上一患者占位数据。已按患者限定占位复用。
- 采购单多行共享全局 `inventoryRows`，后加载行会覆盖先选行名称。已改为按行缓存 + 表单行自身名称。
- 患者时间线/库存页 `?id=` 移除后不清理选中项。已改为 URL 变化时同步为 `urlId ?? null`。
- 随访分页加载期间可勾选上一页行，批量完成作用于不可见行。已禁用加载中的复选框。

## 3. 残余风险
- 审计缓冲为内存队列 + 1 秒定时落盘；SIGKILL/断电会丢最近 1 秒内的审计行（设计取舍，已补正常/孤儿退出冲刷）。
- `member-card` 系列接口的 `requestId` 可选；官方 UI 均携带，第三方直接调 API 不携带时无重放保护。
- `InventoryBatch.create` 的锁守卫仍在事务外（P3）；后续若需与盘点并发强一致可整体移入事务。
- 打包实机安装/升级演练、真实微信网关、CA 证书链路仍属约定范围外。
