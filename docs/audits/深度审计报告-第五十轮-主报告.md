# 深度审计报告-第五十轮-主报告
日期：2026-08-12
基线：`304b992`。本轮启用 2 个只读交叉复核代理（Dirac：前端；Parfit：后端），重点收口上一轮残余项，共修复 20 处问题，并补齐对应回归测试。
## 1. 后端
- 数值边界：validation 对 number/money 增加安全整数上限，`1e300`、`MAX_SAFE_INTEGER+1` 不再能写入通用 CRUD/bulk import/sync。
- 会话安全：refresh claim 不再把原始 access/refresh token 明文写入 IdempotencyRecord，改为 AES-256-GCM 加密（密钥由 JWT_SECRET+tokenHash 派生），并拆到 `auth-refresh-claim.ts` 控制单文件规模。
- 金额上限：会员卡充值/消费/积分、加工单 totalFee、固定佣金 rate 与提成总额统一封顶；加工单 totalFee 同时校验等于明细合计。
- 恢复原子性：restore 改为同目录临时文件 + fsync + rename，复制中断不再留下半覆盖主库；fsync 在只读 fd 平台不可用时降级为尽力而为。
- 补货生成：改用 rowid keyset 分块读取，十万级库存不再整表进内存，且不受 UUID 非单调并发插入影响。
- 批次列表：InventoryBatch.list 加 LIMIT/truncated，效期子集改为 SQL 范围过滤，不再先全量加载再在 JS 过滤。
- 崩溃路径：uncaughtException/unhandledRejection 退出前先冲刷审计缓冲。
## 2. 前端
- 库存工作台：采购单/采购明细/加工单/补货建议/盘点单全部接入 PagePager，fetch 期禁用，超出 pageSize 的数据可翻到第二页。
- 手写分页：Appointments/Refunds 在 placeholder 期禁用翻页；Cephalometric/Imaging 对比分页在 fetch 期禁用。
- 双提交防护：GenerateSection、TemplateSection、ChangeOwnPasswordForm、WechatReminderSettings、CustomFieldsPage、DispenseNarcoticPanel 增加 ref 级 busy 守卫。
- DataTable 稳定性：GlobalSearchPage、hub-tabs CostShareTab、InventoryWorkflowPage 的派生数组 useMemo 稳定，不再每次渲染重置滚动窗口。
- 导航收敛：DashboardPage/GlobalSearchPage 的 `#/` 手写链接改为 react-router `Link`。
- 时间线：PatientTimelinePage 渲染上限 500 条并提示，避免无限加载后 DOM 无界。
