# 深度审计报告-第四十五轮-主报告
日期：2026-08-12
基线：`ddf3668`。本轮启用 2 个只读交叉复核代理（Ampere：前端剩余页面/组件；Laplace：auth/wechat/sync-push/audit/health），并修复 13 处问题。
## 1. 前端
- SearchableSelect/FormBuilder 关系选择：搜索/翻页/作用域重置时清空 prevQueryData，避免旧查询结果与新一轮数据合并造成选项错乱。
- 采购审核行操作增加 busyRef 统一防重入口，提交/通过/驳回/重新提交双击只发一次请求；驳回弹窗也走同一入口。
- ResourceHub 增加 searchTab 声明（患者→患者档案、前台→预约、库存→库存工作台、财务→收费），全局搜索深链不再落到 familyMembers/departments/itemMaster；q 随面板 key 变化重挂载，并作为 initialSearch 传给 ResourcePage/自定义页。
- 预约看板 placeholder 数据期间禁用拖拽、状态下拉与投放，避免把旧日期数据误提交。
- ReviewSummaryBar 增加 placeholderData，刷新期沿用旧计数，消除闪烁。
- ResourcePage 占位数据期间禁用编辑/删除/勾选/批量删除；单删成功后从选中集移除已删 id。
- GlobalSearchPage 的 q 变化时重置资源筛选，并给筛选按钮补 aria-pressed。
## 2. 后端
- changePassword 在事务内重读并重新校验旧密码，管理员并发重置不会再被旧密码改动覆盖（TOCTOU）；同时保留旧密码校验先于新密码长度校验的 401 语义。
- 审计缓冲：已有重试在途时，后续失败批次按容量并入队列由在途定时器统一刷出，不再整批丢弃；仅超容量部分留痕。
- sync/push 校验 deviceId/deviceToken 必须为非空字符串，畸形凭据返回 400 而非 500。
- 微信提醒生成改为按 id keyset 分页遍历候选，超过 1000 条的场景不再永久漏生成。
- refresh 重用后的会话族吊销失败会记录日志并重试一次，不再静默吞掉。
- 密钥临时文件：启动时清扫 tmpdir 中超过 10 分钟的 v2-secrets-*.json；读取侧在 POSIX 上校验文件为 owner-only，否则 fail-closed。
