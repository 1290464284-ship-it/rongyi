## 1. 结论

发现并修复 1 处真实会话缺口：

- `AuthService.logout` 原先只作废 refresh token 并标记 used，已签发的 access token 会一直有效到自然过期（8 小时）。桌面端登出后旧 token 仍能调用 API，形成会话残留窗口。修复为登出事务内 `tokenVersion + 1`，使该用户已签发 access token 立即失效。

其余鉴权路径未发现新 P1/P2：refresh token 轮换 + DB claim 缓存 + 重用即吊销会话族、登录退避锁定、密码重置/禁用/删除即时失效、诊所成员关系失效 403 均已覆盖。

## 2. 修复与验证

- `auth.service.ts`：logout 使用 `runInTransactionImmediate` 原子完成标记 used、清除 refresh token、提升 `tokenVersion`。
- `services-edge.spec.ts`：登出后立即断言旧 access token 报 `Token is no longer valid`。
- 单测门禁 222 文件 / 2250 用例全绿；`typecheck` / `lint` / `knip` 全绿。
